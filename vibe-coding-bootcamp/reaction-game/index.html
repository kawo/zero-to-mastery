    How it works

    1. Press Start session or tap the pad.
    2. The shape turns amber. A random 1–5 s delay is running, so don’t guess.
    3. When it turns green, click, tap or press Space.
    4. Reacting early, or in under 100 ms, counts as a false start and isn’t averaged.
    5. Beat the level’s target 3 times in a row to level up. Higher levels add blue decoys and drop the text cue. Two misses in a row drops you a level.
    6. Rounds under the target can drop power-ups (Shield, Double, Leeway, Calm). Use them between rounds with 1–3. They help you level up but never change your times.
    7. Playing with friends? Tournament lets 2–8 players take turns on this device and ranks everyone at the end.

      How runs are checked
      • Real input only. Clicks and key presses generated by a script are refused.
      • Replay. Each run keeps its 5 rounds (the random delay, when the signal appeared, when you reacted). They’re re-checked every time this list is shown, and the stored score must match them exactly.
      • The game’s own schedule. Every delay must be one the game could have chosen, and every part of the round must add up.
      • Clock integrity. The high-precision timer is compared with the wall clock, which catches slowed or patched timers.
      • Human limits. Averages under 140 ms, less than 5 ms of spread, or reactions that all land on screen refreshes (a bot watching pixels) are excluded.
      • Visible page. The page has to be on screen and focused.
      • Sealed. Runs are signed with a key this page can use but can’t read. Editing saved data breaks the seal.
      • Limits. Everything runs in your browser, so this stops casual cheating (editing saved data, scripts, simple bots and clock tricks), not a determined expert. A shared global leaderboard would need a server.
